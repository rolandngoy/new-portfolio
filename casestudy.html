TrackAI

Understand Today. Ace Tomorrow.

How I designed and built an app that brings a college student's classes, assignments, grades, and study tools into one place.

My role
Designer & developer
Platforms
Web, iOS, Android
Tools
React Native, Expo, GitHub Actions
Timeline
May 2026 – Present

The Problem

College students juggle assignments, due dates, grades, and study material across a pile of disconnected apps and websites. Important things slip through the cracks, and most tools only remind you that a test is coming. They don't help you prepare for it.

Professors face the same problem from the other side: rosters, grading, and class communication all live in different places.

Optional: add what you learned from talking to students.

Students needed one place to track their classes and real help learning the material.

The Solution

TrackAI is one app with two experiences. During onboarding, users choose student or professor, and each gets a dashboard built around how they actually work.

  • For students: join a class with a code, track assignments and grades, and talk with classmates in class chat.
  • For professors: create classes, share join codes, and manage a gradebook.
  • AI study tools: upload notes or readings and get flashcards, summaries, and study notes back.
  • AI Help: a chat for questions about the course material.
  • Built for Washington schools: a directory of 50+ colleges and universities, with Northwest University first.

Process

How I built it

I ran TrackAI the way I learned to run team projects: in short Agile sprints, each ending with something working I could test.

  1. Research & plan

    Mapped the student and professor journeys and where they connect: classes, assignments, and grades.

  2. Design the screens

    Designed onboarding, role selection, and separate dashboards so each user sees only what they need.

  3. Build the features

    Built class management, assignment tracking, the gradebook, class chat, and the AI upload tools.

  4. Test & ship

    Fixed bugs found in real use and set up automated builds for the web, the App Store, and Google Play.

Results & Lessons

TrackAI now has a complete working prototype covering onboarding, both dashboards, class management, assignments, the gradebook, AI study tools, and chat.

Add results: testers, feedback, or launch status.

Test like a real user. A data-saving bug only appeared between sessions. Finding it taught me to test the app the way a student uses it over a full week, not just in one sitting.

Know who each feature is for. Designing for two roles meant every feature had to answer one question before it got built: does a student need this, a professor, or both?
