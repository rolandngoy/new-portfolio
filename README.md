# Roland — Portfolio

Static 5-page site (HTML + CSS, no build step). Deploy with Cloudflare Pages: connect this repo and leave build settings blank.

## Before going live
- Replace every highlighted yellow placeholder and each `<!-- REPLACE -->` image comment.
- Put images in `images/` (keep them under 500 KB).
- contact.html: create a free form at formspree.io and swap in your form ID.
- Update GitHub/LinkedIn links in the footer of each page.
